# Location media credits

All game footage is bundled for offline playback. Each clip is a 15-second, muted, scaled/cropped H.264 adaptation of the source below; short originals are looped. Adapted media retains the source license. These licenses apply to the respective media files, independently of application source code. No Apple TV or SongPop media is included.
